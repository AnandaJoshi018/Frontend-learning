# Color Showcase Web App

A simple and modern **Color Showcase Web App** built using **HTML** and **CSS**.  
This project demonstrates different UI color styles including:

- Normal Colors
- Gradient Colors
- Neon Effects
- Glassmorphism
- Pastel Themes
- Dark Mode Toggle

---

## 🚀 Features

- Responsive card layout using CSS Grid
- Smooth hover animations
- Beautiful gradient color cards
- Neon glow effects
- Glassmorphism UI design
- Soft pastel themes
- Dark mode support
- Beginner-friendly project structure
